## 📚 **学习笔记：GNU/Linux 中的进程管理**

---

### 1. **进程与上下文切换**
- **进程**：是程序的运行实例，一个程序可以启动多个进程。
- **上下文切换**：当 CPU 从一个进程切换到另一个进程时，系统会保存当前进程的状态（寄存器、内存映射等），以便后续恢复执行。

---

### 2. **父进程与子进程**
- 每个进程都由另一个进程创建：
  - **父进程**：创建者
  - **子进程**：被创建者
- 所有进程的祖先是 **init** 进程（PID=1），它是系统启动后第一个进程。

---

### 3. **进程标识符：PID**
- 每个进程有唯一的 **PID**。
- 查看进程命令：
  ```bash
  ps [options]
  ```
  - 常用选项：
    - `x`：显示所有进程（包括无终端的）
    - `a`：显示所有用户的进程
    - `u`：详细信息
    - `-e`：显示系统中所有进程
    - `-f`：完整格式信息
    - `U <user>`：显示指定用户的进程
    - `t <tty>`：显示指定终端的进程

---

### 4. **前台与后台执行**
- **前台执行**：
  - 进程独占终端，直到结束。
  - 使用 `Ctrl+C` 可中断。
- **后台执行**：
  - 在命令后加 `&`，如：
    ```bash
    dd if=/dev/urandom of=file.bin bs=1M count=1000 &
    ```
  - 系统返回：
    - `[任务号] PID`
  - 可同时运行多个后台进程。

---

### 5. **进程管理命令**
| 命令/操作 | 功能 |
|-----------|------|
| `&` | 后台执行 |
| `Ctrl+C` | 终止前台进程 |
| `Ctrl+Z` | 暂停前台进程（转为停止状态） |
| `jobs` | 查看当前会话中的任务（后台或停止） |
| `fg [%任务号]` | 将任务转为前台执行 |
| `bg [%任务号]` | 将已停止的任务转为后台执行 |
| `kill [信号] PID/任务号` | 向进程发送信号（如终止） |
| `killall 进程名` | 根据进程名终止所有匹配进程 |

---

### 6. **常用信号（kill 命令）**
| 信号 | 说明 |
|------|------|
| `SIGTERM`（默认） | 请求进程正常终止 |
| `SIGKILL`（-9） | 强制立即终止进程 |
| `SIGSTOP` | 暂停进程 |
| `SIGCONT` | 恢复已暂停的进程 |

示例：
```bash
kill -9 1234          # 强制终止 PID=1234 的进程
kill -s SIGSTOP %1    # 暂停任务号为 1 的进程
```

---

### 7. **注意事项**
- 进程是全局的，PID 唯一。
- 任务号（如 `%1`）是 shell 内局部编号，不同终端中可重复。
- 使用 `jobs -l` 可查看任务对应的 PID。

---
