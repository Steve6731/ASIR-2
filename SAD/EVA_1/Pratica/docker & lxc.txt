## abrir Virtual Machine Manager
## añadir nueva tarjeta red configuracion xml:
```xml
<interface type="bridge">
  <mac address="52:54:00:f1:22:a1"/>
  <source bridge="2asir"/>
  <vlan>
    <tag id="100"/>
  </vlan>
  <virtualport type="openvswitch" />
  <model type="virtio"/>
  <alias name="net1"/>
  <address type="pci" domain="0x0000" bus="0x07" slot="0x00" function="0x0"/>
</interface>
```

  address 172.20.104.254
  netmask 255.255.0.0
  gateway 172.20.0.1
  bridge_ports enp1s0

```sh
# Distribution configuration
lxc.include = /usr/share/lxc/config/common.conf
lxc.arch = linux64

# Container specific configuration
lxc.apparmor.profile = generated
lxc.apparmor.allow_nesting = 1
lxc.rootfs.path = dir:/var/lib/lxc/gateway.Xuan.2asir.com/rootfs
lxc.uts.name = gateway.Xuan.2asir.com

# Network configuration
lxc.net.0.type = veth
lxc.net.0.link = lan
lxc.net.0.flags = up

```
